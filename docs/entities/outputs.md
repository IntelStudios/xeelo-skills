# Outputs

Notifications, documents, and reports.

## Notification

**Table:** `Notification` (+ conditions, calculations, attachments)

Email templates sent on workflow actions or events.

Key placeholders (from hints):

- `{RequestID}`, `{ObjectName}`, `{CompanyName}`, `{RoleName}`, `{RequestStatus}`
- `{idXXXX}` — request line value by slot
- `{RequestDetail,width}` — request detail table

Full catalog: AdminIntellisense in `140_SyncTables_Misc.sql`

| Column | Semantics |
|--------|-----------|
| `NotificationSubject` | Email subject |
| `NotificationFormat` | Body template |
| `NotificationEmailRequestor` | Send to requestor (Yes/No) |
| `NotificationEmailRole` | Send to new role |
| `IsActive` | Active flag |

Linked from `WorkflowStepAction.NotificationID` or `Workflow.NotificationID`.

## Printout

**Table:** `Printout` (+ conditions, calculations)

Document/PDF templates attached to notifications or workflow.

## Report Structure

**Tables:** `ReportStructure`, `ReportSource`, `ReportResult`, line tables

Report definitions with sources and result layouts.

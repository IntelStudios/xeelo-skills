# Outputs

Documents and reports. Email templates: [notifications.md](notifications.md).

## Printout

**Table:** `Printout` (+ conditions, calculations)

Document/PDF templates. Can be attached to a notification (`NotificationPrintout`) — that junction is not in spec v1.

`{ReportResult,…}` placeholders apply to **printout** HTML, not notification body.

## Report Structure

**Tables:** `ReportStructure`, `ReportSource`, `ReportResult`, line tables

Report definitions with sources and result layouts.

## DB transfer

`Printout`, `ReportStructure` — see [`data/transfer-tables.json`](../data/transfer-tables.json). Notifications: [notifications.md](notifications.md).
